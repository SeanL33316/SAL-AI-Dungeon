# Example scenario setup

SAL does not require scenario-specific code. Your Scenario can describe its own genre, setting, characters, and rules normally.

SAL reads the actual story and asks for flexible future possibilities based on what has already been established.

A useful AI Instructions line is:

> Treat long-term plot guidance as optional. The player's newest explicit choice always has priority. Never force player dialogue, thoughts, feelings, destinations, relationships, commitments, or voluntary actions just to advance a planned beat.

This is optional because SAL already places equivalent player-priority language in the generated arc guidance, but adding it to AI Instructions can reinforce the same behavior.
