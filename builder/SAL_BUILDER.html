SAL — Story Arc Light

Builds the four paste-ready AI Dungeon scripting tabs using the current upstream Story Arc Engine source plus SAL. Inner Self is optional.

Ready. Internet access is required while building.

Install

  1. Build the tabs above.
  2. Copy each generated tab into the matching AI Dungeon scripting tab.
  3. Completely replace the old contents. Do not append a second modifier wrapper.
  4. Save and make sure Scripts Enabled is on.

This builder does not contain a bundled copy of Story Arc Engine or Inner Self. It downloads those projects from their original GitHub repositories when you click Build.
