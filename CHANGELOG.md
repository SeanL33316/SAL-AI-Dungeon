# Changelog

## v1.2.0 — Public SAL release

- Generalized Story Arc Light so it is no longer tied to one scenario.
- Preserved the hard Player Input Priority behavior tested in SAL v1.2.
- Added automatic optional Inner Self coordination.
- Added `/sal` and `/sal status`.
- Changed the generated plan to exactly 8 flexible future possibilities.
- Added immediate persistence of SAL defaults to SAE's settings card.
- Added safe re-use of later user-edited SAE settings.
- Added a public browser builder that fetches upstream dependencies from their original repositories.
- Added third-party attribution and licensing notes.
